Systems

Linux

Linux is the operating system that runs most of the internet's servers. If you deploy anything, you will meet it.

Files and permissions

Everything is a file, and every file has an owner and permissions: read, write, execute, for the owner, the group, and everyone.

ls -l
chmod 644 notes.txt
chown ada notes.txt

Processes

Running programs are processes. List them, find a heavy one, stop it.

ps aux
top
kill 12345

Packages

Software is installed from package managers. On Debian and Ubuntu that is apt.

sudo apt update
sudo apt install nginx
